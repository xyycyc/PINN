  [154] : 本模块承担复合材料温度场重构系统的正演分析任务。其核心目标是在给定材料组成、几何尺寸、温度相关物性、热边界、力学界面和超声激励条件下，计算复合材料内部的温度场、热变形与预应力状态，并进一步求解超声波在非均匀温度场和复杂界面中的传播、反射、透射及衰减过程。与仅输出单一温度或位移结果的常规分析不同，本模块需要保持热场、固体场和超声全波形之间的数据连续性，使每一个声学特征都能够追溯到对应的材料状态和温度分布。
  [155] : 研究对象覆盖三类具有代表性的复合材料：一是具有明确层间界面的多层材料；二是由连续金属基体和随机颗粒组成的金属基复合材料；三是具有周期纤维细观结构、需要通过均匀化向宏观尺度传递参数的碳基或硅基复合材料。研究范围同时包含一维与二维、稳态与瞬态计算。一维模型用于厚度方向的快速参数分析和大批量样本生成，二维模型用于描述横向非均匀性、显式颗粒、界面波动以及多尺度宏观响应。

  [443] 6: 声学数据采集与处理
  [444] : 在多探头超声信号采集过程中，计算机通过程序控制数字示波器、四通道高压超声切换单元以及温度采集模块，实现多探头超声波形的自动化轮询采集。实验开始后，程序首先对四通道高压超声切换单元进行初始化配置，并依次选通CH1~CH4通道，分别采集各超声探头在空载状态下的20帧超声波形数据。针对不同探头灵敏度、传播路径及响应特性的差异，程序分别计算各通道有效回波窗口内的空载能量、峰峰值和RMS特征参数，建立对应探头独立的空载基线模型。
  [445] : 四个探头安装在同一个固定器上，并同时与材料保持接触。完成基线建立后，系统进入多通道轮询采集模式。程序按照预设周期控制四通道高压超声切换单元依次选通不同探头通道，每次通道切换完成后设置固定等待时间，以消除开关切换过程中的电气瞬态影响。随后，程序实时读取数字示波器采集的超声波形数据，并基于状态机方法对当前探头与材料之间的耦合状态进行判断。首先通过比较当前波形与对应通道空载基线之间的能量、峰峰值及RMS特征差异，判断探头是否进入接触候选状态；当连续多帧波形在幅值变化、波形相关性以及回波峰值位置方面均满足稳定判据时，系统判定该探头与被测材料达到稳定耦合状态，并自动进入固定窗口采集阶段。

## image39.png body=451 pixels=1067x697 display=5.906x3.858in mean=171.59 dark100=0.2311
  [447] : 单个探头完成采集后，程序不再依赖人工判断波形恢复状态，而是直接进入通道切换流程，关闭当前通道并自动选通下一探头通道，重复执行固定窗口采集过程。最终，系统依次完成CH1~CH4四个探头的超声信号采集，实现基于时分复用方式的多探头超声波形自动化、连续化和标准化采集。完成当前温度点的全部波形采集后，所有探头移离测试位置，系统等待材料达到下一设定温度点，并重复上述采集流程。
  [448] : 高温瞬态加热实验中，采用程序控制方式实现多探头超声波形快速采集。实验开始前，将超声探头固定于多探头固定器上，并通过四通道高压超声切换单元完成各探头通道配置。实验过程中，通过温度采集模块实时监测试样温度，当指定热电偶测得材料温度达到目标温度（1500 K，约1227 ℃）时，将安装有四个超声探头的固定器快速送入加热舱内，使各探头同时与材料表面接触。探头接触后，程序立即触发超声信号采集，并控制四通道高压超声切换单元按照预设顺序快速选通CH1~CH4通道，依次获取四个探头对应的超声响应波形。每个通道切换后设置短暂稳定等待时间，以消除切换过程中的电气瞬态影响，并锁定当前通道的有效超声波形数据。
  [449] : 完成四个通道波形采集后，程序同步读取温度采集模块数据，并将各探头编号、采集通道、温度信息以及对应波形数据进行关联存储。波形数据保存为CSV格式，同时生成对应波形图像，实验参数以JSON格式记录。随后，将探头固定器移出加热舱，使探头和材料自然冷却，待系统恢复至下一次实验条件后，重复上述过程，实现高温瞬态条件下多探头超声信号的快速采集。
  [450] : 对采集数据进行统一整理和处理，提取各位置的第一次回波和第二次回波的超声波声时，并计算第二次回波幅值比上第一次回波幅值。最终获得稳态以及瞬态条件下物块上表面探测位置对应的声时及相关热电偶的温度数据。TOF单位：微秒，温度单位：℃。 TC*_C列表示*位置的热电偶的温度数据，位置数据详见 REF _Ref235906486 \h 图 3.39。ABCD分别代表四个超声探头，探头在试材上的放置位置见 REF _Ref235906462 \h 图 3.40。

  [542] 5: 研究目标与总体技术路线
  [543] 3: 本模块承担复合材料温度场重构系统中的快速智能解算任务。研究目标是以超声全波形为直接观测量，在保持声时、幅值、衰减、频谱及传播时序信息的基础上，学习超声响应与材料内部温度场之间的非线性映射，实现一维、二维、稳态和瞬态温度场的快速重构。与依赖迭代优化的传统反演过程相比，人工智能模型在完成训练后可直接输出固定物理节点上的完整温度场，并通过统一评价口径给出代表性测点误差和单场推理耗时。
  [544] 3: 研究对象覆盖两层W30Mo70钨钼合金多层材料、W基体/SiC纤维金属基复合材料和SiC纤维/CVI-SiC基体硅基复合材料。仿真数据由热声固耦合分析形成超声波形—温度场配对样本，实验数据由项目试验及多参数处理流程提供波形与测温记录。三类材料采用统一的数据格式和模型接口，通过材料标识、独立checkpoint和材料路由实现分类管理。
  [545] 3: 总体技术路线由数据构建、波形预处理、模型训练、温度场预测、精度与效率评价、在线增量训练六个环节组成。波形经裁剪、平滑、趋势校正和归一化后形成统一张量；CNN与LSTM分别提取局部形态和传播时序特征；BP全连接网络完成融合回归；MSE监督损失与PINN物理约束共同提高数值精度和空间连续性；预测结果以二维完整场、一维中心线、五测点统计和标准化文件形式输出。
