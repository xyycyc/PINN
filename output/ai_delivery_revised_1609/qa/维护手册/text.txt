维护手册 
超声波全波形温度场重构理论及方法研究 
适用范围  基于人工智能的温度场反演方法模块 
本手册用于基于人工智能的温度场反演方法模块的数据维护、模型维护、参数配置管理、结果归
档和运行核查。维护工作围绕数据清单、固定物理节点、材料模型、训练配置和结果文件的对应
关系展开，保持建库、训练、预测与在线增量更新流程一致。 
1 系统与运行资料管理 
1.1 系统组成 
系统在 Windows 平台运行。Python 承担图形化界面、数据库构建、模型训练、预测、增量训练
和结果导出，Fortran 承担预测指标等数值计算，通过配置文件、数据文件和标准调用接口完成
数据交换。项目软件资源包括 Windows 10/11、Visual Studio 2022、Intel oneAPI Fortran、
Python 3.10 及相关科学计算和人工智能开发工具。 
人工智能模型以统一长度的超声全波形张量为输入，采用 CNN 与 LSTM 双分支提取局部形态和传
播时序特征，经 BP 全连接网络融合后生成完整二维温度场。一维温度分布由二维场归一化 
x=0.50 固定中心线提取。

1.3 版本对应关系 
程序文件、技术文档、输入输出文件及接口说明保持版本一致。维护资料随任务保存输入条件、
运行配置、输出结果和说明文件，重要版本登记版本号、修改记录和运行日志。 
  
第 2 页 
2 数据库与固定节点维护 
2.1 分类存储和索引 
以 case 为单位管理超声接收波形、温度场节点数据及配置文件。按材料和数据处理阶段组织目录，
通过 manifest 登记样本编号、材料类型、温度、维度、稳态或瞬态类别、波形路径、温度场路径
与数据来源。 
资料类别 维护内容 
原始资料 raw 及 case 目录中的原始波形、温度场和配置，保留数据来源与原始工况。 
处理资料 data_process 中的预处理结果、索引和配对记录，以及 waveforms、
temperature_fields 和固定采样数据。 
样本清单 manifest.json、train_manifest.json、validation_manifest.json、
test_manifest.json。 
划分与采样 split_config.json、mesh_audit.json、sampling_index.npz，保持各清单与采样
定义对应。 
多材料集合 material_collection.json 中的材料清单、数据划分和模型路由关系。 
 
2.2 配对与采样维护 
1. 按照样本编号和材料信息核对超声波形与对应温度场，统一时间列、幅值列、温度单位和坐标
单位，完成样本配对。 
2. 保存确定性空间分层采样形成的10000 个固定物理节点，以及原始节点编号、物理坐标、温度
标签、材料组分、边界身份和接触界面两侧身份。 
3. 训练、验证、测试和预测沿用同一固定采样索引；训练集、验证集和测试集按材料独立配置，
验证清单用于模型评估和最佳权重选择。 
4. 通过“校验数据”检查数据规模、格式、温度范围、网格和采样一致性，保存数据核查报告。 
2.3 原始资料保存与备份 
源代码、仿真数据和试验数据分类存储并定期备份。原始超声波形及热电偶温度数据设置为只读
或单独保存，数据处理在副本上开展；保留预处理、温度场反演和误差计算形成的中间文件与结
果文件。 
  
第 3 页 
3 模型与训练配置维护 
3.1 材料模型及调用关系 
每种材料保存独立的完整checkpoint、数据清单和模型路由。材料标识将数据集、模型权重与调
用关系关联起来。维护时核对材料集合中的清单和路由，保持材料特定的数据统计量、预处理参
数、固定节点信息和模型权重对应。 
运行任务时核对checkpoint 记录的模型类型、节点数量、采样指纹、波形长度、温度统计量和预
处理参数，使训练、预测及增量训练采用一致的物理节点定义和数据处理规则。 
3.2 训练模式与物理约束 
训练支持MSE 监督模式和MSE 与PINN 物理约束组合模式。MSE 约束预测温度与参考温度的数值偏
差；PINN 根据固定节点坐标、材料分区及空间邻接关系构造物理残差，并结合场分布平滑约束共
同参与训练。 
训练目标由MSE 监督损失、物理约束损失和平滑损失加权组成，物理约束与平滑损失权重按任务
配置保存。接触界面两侧保留独立材料与界面身份，在构造邻接关系和平滑约束时保持各自的物
理对应关系。训练配置、损失模式及权重随模型版本保存。 
3.3 在线增量训练与参数冻结 
1. 加载基础checkpoint，同时读取数据统计量和任务配置。 
2. 导入新增实验波形及对应温度记录，关联材料类型、维度和稳态或瞬态工况。 
3. 保持已经验证的训练参数、预处理规则、测点映射和关键训练条件一致，按冻结配置保留通用
特征参数，更新指定参数。CNN 和LSTM 通用波形表示按配置保留，BP 融合层或指定参数随新增数
据调整。 
4. 训练结束后保存新的checkpoint、损失日志、冻结配置、权重更新记录及版本信息。基础模型
与增量模型分别保留，结果写入独立目录。 
模型维护记录通过训练前后模型文件、训练日志和更新记录关联新增数据、参数变化及模型版本，
基础模型和增量模型均可独立加载。 
  
第 4 页 
4 结果维护与运行核查 
4.1 结果文件归档 
归档对象 保存内容 
温度场结果 节点编号、坐标、预测温度、参考温度、材料和界面身份，完整二维场数组及一维
中心线结果。 
图形与指标 参考场、预测场、空间误差分布、中心线曲线、五测点与全场及分区误差、独立测
速记录。 
模型与任务 对应 checkpoint、数据清单、任务配置、运行环境元数据、预测日志和模型版本。 
文件形式 按任务目录保存 CSV、NPZ、JSON、PNG 和运行日志，建立模型、数据、配置与结果
的关联。 
 
4.2 固定测点与精度核查 
测点使用相对试件宽度和厚度的归一化坐标。首次在固定物理节点中确定最近节点后固化node_id，
并在全部样本及四类工况中复用。分别求五个参考温度和五个AI 预测温度的算术平均值，再计算
两者相对误差。 
W30Mo70 实验验证覆盖一维稳态、一维瞬态、二维稳态和二维瞬态，五测点平均温度相对误差分别
为 0.7221%、3.3637%、0.7095%和3.3221%，满足不大于10%的指标要求。核查时保持测点映射、
材料及工况信息与对应实验记录一致。 
4.3 运行与效率核查 
核查数据导入、模型训练、增量更新、预测和结果可视化各环节的输入输出，保存跨语言调用结
果及异常返回记录。采用GPU 加速和并行推理完成二维温度场重构，按完成同一完整温度场任务
的平均时间统计效率。 
报告记录4 个完整温度场总推理耗时约0.248766 s，平均约0.0622 s/场；相对共轭梯度法、灵
敏度法和最速下降法的加速比分别约为 300.2、178.5 和 200.0。效率记录与对应模型、输入数据、
计算环境和精度结果一起归档。 
4.4 维护资料核对 
逐项核对文件名称、数量、版本、内容和可读性，检查输入条件、运行配置、输出结果及说明文
件是否对应，保持程序、数据和技术文档之间的材料名称、参数定义、评价方法及结果记录一致。
