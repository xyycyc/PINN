# 历史交付资料归档

本目录内原有文件属于交付文件及其生成、检查过程。维护分支的现行操作说明见[文档索引](../docs/README.md)，版本差异和修复见[重构记录](../docs/refactoring.md)。

| 目录 | 归档内容 |
| --- | --- |
| `ai_delivery_docs_20260906/` | 程序使用说明、维护手册、调试维修方法、培训记录，以及改名和 QA 版本 |
| `ai_delivery_revised_1609/` | 修订交付文件与 `before_delivery` 对照资料 |
| `training_reference_revision/` | 培训参考资料修订与原有对照文件 |

其中的 `final` 表示相应交付批次的最终文件，不代表当前维护代码的最新操作手册。历史数据、截图、培训及验收内容保留；本轮没有重新训练或重测其中的性能结果。目录内生成脚本中的旧盘符和交付源文件路径属于归档上下文，未作为运行代码进行批量改写。

交付代码与原有非忽略文档备份在 [`submitted`](https://github.com/xyycyc/PINN/tree/submitted)；原始数据、模型权重、DLL 和运行结果仍需按项目忽略规则另行保存或构建。
