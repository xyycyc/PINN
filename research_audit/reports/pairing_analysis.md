# Pairing analysis

| Pairing type | Count | Evidence |
|---|---:|---|
| Simulation waveform↔field exact local pair | 1400 | Same case directory plus ultrasonic config reference to the case thermal CSV |
| Simulation internal failures | 0 | Filesystem/config scan |
