- 增量训练当前优化全部模型参数，没有冻结 CNN/LSTM 的用户开关。加入冻结策略属于训练功能变化，需要单独确定冻结哪些层、何时解冻以及验收数据。

- 历史五测点误差、加速比是交付记录，不是本次重构重跑的结果。算法或输入变化后需要重新评估。

## 结构与操作改进

- `cli.py` 只解析和分发；`cli_arguments.py` 定义参数；`commands.py` 将原来的长分支拆为六个处理函数。已逐个比对处理函数的 AST，业务执行语句与交付版一致。
- 包公共导出按需加载，旧导入名称继续可用。帮助命令在没有 site-packages 的 Python (`-S`) 下也能执行。
- `paths.py` 统一根目录、包名前缀和用户目录解析；没有批量替换外部绝对路径。
- `run.py` 支持在项目根或任意工作目录使用绝对脚本路径启动；`--gui` 打开界面，其余参数传给 CLI。
- 同机单次测量：`python -m ai_model --help` 从约 2.58 s 降至 0.08 s；`import ai_model` 从约 2.60 s 降至 0.04 s。该数字仅说明启动依赖减少，不能据此推断训练或推理加速。
- 自动化测试可以直接在仓库根运行 `python -m pytest -q`。
